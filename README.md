# Auth Prototypes: Federated Instances + Centralized Authentication

Design prototypes for RelativityOne authentication UX, built on the MFE applet
template with relativity-ui.

- Live demo: https://lukaszzembrzuski1.github.io/federated-instances-prototype/
- Federated Instances: #/ route
- Centralized Authentication user management: #/users route

## Run locally

    npm install
    npm run dev

Dev server: http://localhost:4077 (packages resolve from Relativity Artifactory;
run npm login against it if installs return 401).

Built output is deployed to the gh-pages branch.
